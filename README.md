<h2 align="center">✦&nbsp; 功能明细 &nbsp;✦</h2>

<h4 align="center">浏览与发现</h4>

<p align="center">·&nbsp; 最新、热门、公开与账户个性化推荐</p>
<p align="center">·&nbsp; 标签、声优、社团、年龄分级与官方榜单</p>
<p align="center">·&nbsp; 本地屏蔽规则，可按作品、社团或标签过滤</p>
<p align="center">·&nbsp; 高级搜索：网站式表达式、结构化候选与结果筛选</p>
<p align="center">·&nbsp; 作品详情含标签、参演、社团、相似作品、相关作品与完整文件目录</p>

<h4 align="center">外部音源</h4>

<p align="center">·&nbsp; 需要网页验证的来源提供独立验证流程</p>
<p align="center">·&nbsp; 支持多个来源并存，可在来源列表中切换</p>
<p align="center">·&nbsp; 来源目录层级浏览，音轨可直接加入播放队列</p>
<p align="center">·&nbsp; 兼容多种分发形式，包括直链、分段传输与流式清单</p>
<p align="center">·&nbsp; 以只读方式挂载额外的作品来源，与主站内容分开浏览</p>

<h4 align="center">播放与音效</h4>

<p align="center">·&nbsp; A-B 循环：在时间轴上选取区间反复播放</p>
<p align="center">·&nbsp; MiniPlayer 与全屏播放器之间的卡片转场</p>
<p align="center">·&nbsp; 按音效与格式偏好自动选择音轨和版本目录</p>
<p align="center">·&nbsp; 播放队列、后台播放、锁屏与系统媒体控制</p>
<p align="center">·&nbsp; 均衡器、音量阈值、场景效果、声道模式与播放速度</p>

<h4 align="center">字幕与歌词</h4>

<p align="center">·&nbsp; 画中画悬浮歌词</p>
<p align="center">·&nbsp; 全屏字幕、同步歌词与单双行自适应排版</p>
<p align="center">·&nbsp; 字幕与作品关联管理，支持批量修改与清理</p>
<p align="center">·&nbsp; 支持 LRC、SRT、VTT 与 TXT，可手工指定编码</p>
<p align="center">·&nbsp; 从压缩包导入字幕：逐条校验、路径匹配、失败回滚，导入前可预览</p>

<h4 align="center">账户与同步</h4>

<p align="center">·&nbsp; 账户登录，凭据保存在系统 Keychain</p>
<p align="center">·&nbsp; 收藏、作品状态、评分与评论双向同步</p>
<p align="center">·&nbsp; 本地头像按账户隔离，退出登录后仍保留</p>
<p align="center">·&nbsp; 播放列表的创建、编辑、排序、分享与关注</p>

<h4 align="center">记录与统计</h4>

<p align="center">·&nbsp; 播放历史与继续收听</p>
<p align="center">·&nbsp; 收听日历与热力图，可按年、月查看对比</p>
<p align="center">·&nbsp; 收听统计：时长、作品数、音轨数、活跃天数</p>
<p align="center">·&nbsp; 播放断点本机保存，进入作品时可选择是否询问续播</p>

<h4 align="center">隐私与存储</h4>

<p align="center">·&nbsp; 断点、头像与偏好仅保存在本机</p>
<p align="center">·&nbsp; 凭据不外泄，项目不记录密码或令牌</p>
<p align="center">·&nbsp; 应用切换时模糊遮挡，避免封面外露</p>
<p align="center">·&nbsp; 存储管理可查看占用并按容量或时间清理</p>
<p align="center">·&nbsp; 音频缓存可复用已播放片段，支持容量上限与保留期</p>

<h2 align="center">✦&nbsp; 源码结构 &nbsp;✦</h2>

```text
NeiroApp/
├─ Sources/
│  ├─ App/             应用入口、根导航与环境注入
│  ├─ DesignSystem/    主题、图片加载与通用组件
│  ├─ Features/        首页 · 详情 · 播放器 · 搜索 · 资料库 · 外部音源
│  │   └─ Player/PiP/  悬浮歌词模块
│  ├─ Models/          API、播放与账户模型
│  └─ Services/        网络、认证、播放、字幕、缓存与本地存储
└─ Resources/          App 图标与资源

project.yml            XcodeGen 工程定义
.github/workflows/     无签名 IPA 的 CI 构建
tools/                 构建及维护脚本
```

<h2 align="center">✦&nbsp; 本地构建 &nbsp;✦</h2>

<p align="center">
  需要 macOS、Xcode 16 或更高版本，以及 XcodeGen；也可以直接生成无签名 IPA，自行签名或用 SideStore、AltStore 侧载
</p>

```bash
brew install xcodegen && xcodegen generate && open Neiro.xcodeproj
./tools/build_unsigned_ipa.sh
```

<h2 align="center">✦&nbsp; 数据 · 隐私 · 版权 &nbsp;✦</h2>

<p align="center">
  头像、播放断点与部分偏好仅保存在本机。<br>
  登录凭据由本机 Keychain 保存，项目不记录密码或令牌。<br>
  收藏、评分、评论、进度与播放列表写入用户自己的 ASMR.ONE 账户。
</p>

<p align="center">
  仓库代码许可不覆盖上述数据及任何第三方内容。<br>
  应用不托管音频、封面与字幕，这些内容来自 ASMR.ONE。<br>
  Neiro 是独立的非官方客户端，与 ASMR.ONE、DLsite 及作品作者无从属关系。
</p>
